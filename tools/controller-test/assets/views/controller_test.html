Prisma Controller Probe

Hold Back for 650 ms to open. Normal mode: right stick moves the pointer, A is a virtual left click, B and D-pad stay native converted keys, and X/Y, bumpers, triggers, Start, and stick-clicks are bound action probes. The OSK section below rebinds A, B and the D-pad while the keyboard is open. Native Gamepad mode replaces all of that with the navigator.getGamepads path.

On-screen keyboard

A on a Keyboard button opens the shared OSK. While it is open, A, B and the D-pad are bound as actions for the OSK and stop acting as click and browser keys. LB/RB change layout, B cancels, Done commits, Paste reads the clipboard.

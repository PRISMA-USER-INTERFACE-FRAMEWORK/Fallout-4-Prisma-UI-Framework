# PrismaUI 2.2.0

**Release date:** 2026-09-22

PrismaUI 2.2.0 is a controller-reliability release built on the larger [2.1.1 platform update](2.1.1-release.md).

## Controller bridge recovery

Controller-action bridge recovery is now framework-owned.

- Failed JavaScript bridge installs are retried through the deferred Ultralight queue.
- Retries are bounded to three attempts per view generation.
- Reload, clear and destroy invalidate stale retry state.
- Pending and ready bridges do not start duplicate installs.
- Completion from an older generation cannot overwrite a newer view generation.
- Consumer mods can stay thin: bind semantic actions and focus-entry callbacks and let PrismaUI own physical routing, repeat state, bridge installation and recovery.

The public V1-V12 ABI did not change for this recovery.

## 2.1.1 platform changes included in the current line

The current framework line also includes:

- native controller input on Fallout 4 1.10.163 and Anniversary Edition 1.11.240;
- native Gamepad mode for live stick and trigger values;
- V4 JSON localization with loose/BA2 loading, locale detection, English fallback, dotted keys and interpolation;
- the preferred `PrismaUI_F4_Modern_API.h` feature-table discovery API;
- restored in-game Ultralight DevTools on F12;
- foreign-hook and mixed-ownership graphics recovery;
- per-view cursor ownership;
- serialized input-window subclass installation and activation recovery;
- versioned FOMOD packaging, optional developer headers and release provenance checks.

## Compatibility

The numbered `PrismaUI_F4_API.h` V1-V12 ABI remains supported. Existing consumers do not need a rebuild solely for 2.2.0.

For new integrations, prefer [Modern API](modern-api.md) discovery when you want explicit feature/version checks.

# API by feature

The modern header groups the API into small feature tables. Discover only the tables you need; each table lists its methods with links to the full documentation.

| Table | Use it for |
| --- | --- |
| [Core](core) | One table with the original surface: view lifecycle, page messaging, health, enumeration, suppression and offscreen helpers. |
| [Controller](controller) | Gamepad state, prompts, roles, overlays, controller actions and native gamepad mode. |
| [Game-thread](gamethread) | Verified game-thread dispatch, thread checks and game-thread page events. |
| [Meta](meta) | Provider identity, API build information and capability discovery. |
| [View](view) | The focused view surface: create, show, hide, focus, health, plus per-view cursor policy. |
| [Interop](interop) | C++ to page and page to C++ messaging: invoke, interop calls, JS listeners, UI events and console callbacks. |
| [Localization](localization) | Legacy Fallout-string translations plus V4 JSON localization. |
| [Render](render) | Offscreen rendering, texture views and binding a view to geometry or a screen material. |
| [Input](input) | Scrolling compatibility and selective input regions for overlays. |
| [Menu](menu) | HUD and menu suppression, activate-choice capture and view enumeration. |

If you are not sure where to start, the numbered API in [API reference](../api-reference) has the same calls in one interface, and [Modern API](../modern-api) explains the difference.
